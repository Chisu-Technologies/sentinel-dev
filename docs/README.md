# Documentation for Sentinel for developers

Status: planned design, not implemented.

Sentinel for developers is pre-alpha and nothing in it is installable yet. These pages
describe the planned design. Each page says what is decided and what is not. Where a
detail is not decided, the page says "not yet decided" instead of guessing.

Start with the [README](../README.md) for the short version.
