# Third-party notices

This repository has no third-party dependencies yet.

Every dependency we redistribute will be listed here with its license, and the license
text will ship with it. The components we expect to use are:

- the official Go SDK for MCP: Apache-2.0 for new contributions and MIT for the
  earlier code;
- go-keyring: MIT;
- codebase-memory-mcp: MIT.

Nothing is redistributed yet, so no license texts are included yet. They will be added
together with the first release that ships any of these components.

This list states intent, not a commitment: an entry only counts once the dependency is
actually redistributed and appears in a section of its own below.
