# ===========================================================================
# Sentinel sandbox — Squid ALLOW-LIST de dominios (PHASE4 §2.1 / §7).
#
# Deny-by-default: el proxy SOLO permite los dominios listados aquí. Todo lo
# demás se rechaza. Esta es la ÚNICA salida a internet del contenedor efímero
# (red restringida sentinel_sandbox_net → pkg-proxy). Código NO confiable del
# repo objetivo no puede exfiltrar datos ni hacer SSRF: no hay otra ruta.
#
# FORMATO (Squid `dstdomain`): un dominio por línea, SIN el punto inicial. En
# Squid, `dstdomain ejemplo.com` ya cubre `ejemplo.com` Y TODOS sus subdominios
# (api.ejemplo.com, etc.). NO añadir además `.ejemplo.com`: Squid lo rechaza
# como redundante ("'.x' is a subdomain of 'x'") y ABORTA el arranque (FATAL).
# Por eso aquí va solo la forma sin punto.
#
# POLÍTICA DE EDICIÓN: añade dominios SOLO cuando un stack los necesite para
# instalar deps. Mínimo por stack (least-privilege). Revisión del operador
# requerida para cualquier alta (es la frontera de egress de código no confiable).
# ===========================================================================
